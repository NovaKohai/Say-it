# Say-it 🎙️💸

**Say It** is a modern, native Android application for expense tracking, installment & debt payoff management, and AI-powered financial insights tailored for Egyptian Pounds (EGP) and dual-language (Arabic & English) users.

## ✨ Features
- 💰 **Expense & Budget Tracking:** Real-time monthly budget tracking with daily burn rates.
- 📅 **Installments & Debt Payoff:** Track BNPL (ValU, Souhoola, Sympl, Aman, Forsa) and bank credit cards with interactive Bézier payoff curve graphs.
- 📩 **Automatic SMS & Notification Parsing:** Instant extraction of financial transactions from Egyptian banks and BNPL providers.
- 🤖 **AI Financial Copilot:** Local & Cloud AI companion conversing in authentic Egyptian Arabic and English.
- 🎨 **FinTech Glassmorphism Design:** Built with Jetpack Compose following Emil Kowalski's tactile micro-interaction principles.
- ⚡ **Clean Architecture:** Domain-driven design with strict layer separation and offline-first persistence.

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Architecture:** Clean Architecture + MVVM
- **Database:** SQLite Local Storage
- **Build System:** Gradle Kotlin DSL
- **Minimum SDK:** 24 (Android 7.0+)
- **Target SDK:** 36
